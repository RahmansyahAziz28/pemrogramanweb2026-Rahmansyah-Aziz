# Jobsheet 3 (Versi Bootstrap) — Responsive Design dengan Framework

Sub-CPMK: Membangun tampilan responsif memakai framework CSS (Bootstrap 5).

Versi ini adalah implementasi sistem **Crime Records (Gotham City Police Department)** menggunakan Bootstrap 5.3 CDN.

## Fitur & Implementasi
- **Framework:** Bootstrap 5.3 dimuat via CDN (`bootstrap.min.css` & `bootstrap.bundle.min.js`).
- **Navbar:** Navigasi responsif menggunakan komponen navbar collapse Bootstrap (`.navbar-toggler`, `.collapse`).
- **Tata Letak:** Grid responsif Bootstrap 12 kolom (`.row`, `.col-md-6`) untuk kartu statistik beranda.
- **Tabel Responsif:** Menggunakan utilitas `.table-responsive` dengan tema tabel gelap Bootstrap (`.table-dark`, `.table-striped`, `.table-hover`).
- **Form:** Menggunakan form control Bootstrap (`.form-control`, `.form-select`).
