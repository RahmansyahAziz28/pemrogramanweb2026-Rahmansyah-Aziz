# PustakaHub

Sistem informasi manajemen perpustakaan berbasis web statis menggunakan HTML.

## Struktur Proyek

```
jobsheet-1/
├── index.html
├── item/
│   ├── index.html
│   └── add.html
└── user/
    ├── index.html
    └── add.html
```

## Halaman

| Halaman | Deskripsi |
|---|---|
| Dashboard | Ringkasan jumlah buku, anggota, dan kategori pustaka |
| Koleksi Buku | Tabel daftar buku dengan kode, judul, kategori, dan jumlah |
| Data Anggota | Tabel daftar anggota dengan username, nama lengkap, dan sandi |

## Fitur

- Dashboard statistik perpustakaan
- Manajemen koleksi buku (daftar buku dan form tambah)
- Manajemen data anggota (daftar anggota dan form tambah)
- Navigasi sidebar antar halaman
